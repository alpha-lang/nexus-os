# Scripts one-shot

Ce dossier contient des scripts ponctuels utilisés pendant le développement
initial du projet (patchs de schéma Prisma, scripts de vérification, etc.).

⚠️ **Ne pas exécuter en production.**

Ils sont conservés uniquement pour référence historique.
La plupart sont déjà obsolètes.

## Structure
- `api/` — scripts liés au backend NestJS (apps/api)
- `web/` — scripts liés au frontend Next.js (apps/web)

## Voir aussi
- `/scripts/` — autres scripts actifs
- `package.json` du monorepo — commandes officielles
